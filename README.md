# 100 Days of Python

This repository contains my projects and programming exercises from Angela Yu's **100 Days of Code: The Complete Python Pro Bootcamp**.

I am currently working through the course as part of my self-directed learning while preparing to begin my second bachelor's degree in Computer Engineering at the University of Central Florida.

## About

Each folder represents a day of the course and contains the projects and exercises I completed while learning and practicing Python.

So far, my work has included projects such as:

* Tip Calculator
* Treasure Island
* Rock, Paper, Scissors
* Password Generator
* Hangman
* Caesar Cipher
* Blind Auction
* Calculator
* Blackjack

Through these projects, I have been practicing fundamental programming concepts including:

* Variables and data types
* Conditional statements
* Loops
* Functions
* Dictionaries
* Lists
* User input and validation
* Randomization
* Problem-solving and program logic
